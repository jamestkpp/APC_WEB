# Ayutthaya Polytechnic College Website

ตัวอย่างเว็บไซต์สีน้ำเงินที่มีระบบเพิ่มหน้าและเมนูจากหน้าผู้ดูแล (Admin Console) พัฒนาโดยใช้ Node.js และ Express

## คุณสมบัติ
- แสดงเมนูจากข้อมูลใน `pages.json`
- เพิ่มหน้าใหม่ผ่าน `/admin` (รหัสผ่านเริ่มต้น `admin` หรือกำหนดผ่านตัวแปร `ADMIN_PASSWORD`)
- แบนเนอร์ยอมรับคุกกี้และประกาศ PDPA
- ใช้ Bootstrap 5 และดีไซน์สีน้ำเงิน

## การใช้งาน
1. ติดตั้งแพ็กเกจ
   ```bash
   npm install
   ```
2. เริ่มเซิร์ฟเวอร์
   ```bash
   node index.js
   ```
3. เปิดเว็บที่ `http://localhost:3000`

## โครงสร้างไฟล์ที่สำคัญ
- `index.js` – ไฟล์หลักของแอปพลิเคชัน
- `pages.json` – เก็บข้อมูลหน้าที่สร้างผ่านผู้ดูแล
- `views/` – ไฟล์เทมเพลต EJS
- `public/` – ไฟล์ CSS/JS สาธารณะ
